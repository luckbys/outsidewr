# Modelos da Tripo

Os GLBs reais baixados da API ficam nesta pasta com os IDs do catálogo em
`tools/tripo_catalog.json`. Nenhum modelo de exemplo é apresentado como geração
real. Sem os arquivos, o jogo continua usando os modelos procedurais existentes.

Geração e importação: consulte `docs/TRIPO_ASSETS.md`.
